# S19m: interrupted watch-removal cleanup

Watch removal writes bounded owner-scoped cleanup intent in the same transaction
that clears watch metadata. Normal cleanup clears intent after checked inode unlink.
Public locator_watch_cleanup drains owned intents under the observer writer lease,
excludes active/unsafe runtime leases and rejects still-registered identities.
It preserves source/locator/index evidence and is repeatable without a root grant.

Native process regression pauses immediately after removal metadata commit, sends
SIGKILL and verifies the private orphan lease remains. Foreign-owner cleanup cannot
drain it; a held lease is retained; after release cleanup removes it and repeats
without further changes. Test pause is confined to the existing test-fault build.
Both normal and sanitizer configurations use actual process death.

Eight pending intents bound recorded cleanup backlog; further removals refuse before
mutation at capacity. Atomic runtime admission and late-admission crash races remain
required to qualify all orphan cases. Broad resource/fairness/service lifecycle and
reindex scheduling/full Sources release also remain open.
