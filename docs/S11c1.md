# S11c1 — owner-bound immutable source claims and cached provenance

C02/C05/C06/C11 subset and prerequisite for S11c live locator reconciliation.
Sources currently deduplicates snapshot bytes by SHA, but read authority and the
first stored locator are not owner-scoped. Deliver owner-bound registration claims
and evidence-cache reuse: knowing another owner's content SHA never grants access
or their locator provenance. Identical bytes may still share the private immutable
payload while public claims retain each owner's admitted locator/media.

Included: sources.c, native scope tests, public source contract/docs/Makefile and
text/PDF/index regressions. Add bounded owner/id/media claims (max256 globally,
no eviction), created only after native registration verifies granted source bytes.
Read/cache admission requires that exact owner's media claim. Salt private cache
keys with host-configured owner. Keep public source/version SHA and literal evidence
semantics unchanged. Do not automatically grant unclaimed old prerelease snapshots;
explicit re-registration establishes authority. Old private caches are not trusted
across the new owner key. Existing completed Agent semantics stay owner-owned.

Acceptance: Alice registration/read, Bob cannot read known SHA or warmed cache;
Bob registers identical bytes at a distinct permitted locator and receives only
Bob provenance; Alice remains unchanged. PDF media claims and unsupported owner
configuration refuse correctly. Actual256-claim quota, retained existing claim,
strict native text/PDF/inventory/index regressions, Mac/Linux sanitizers and copied
independence. No new business dependency and no Python. Focused commands recorded
when the runner exists. Completes only after all required cases pass.

Reason for this named prerequisite: live locator records must not inherit another
owner's immutable provenance or read authority. S11c2 then implements locator.c/h
from S11c.md. S11b2 final qualification must finish before implementation starts.
This remains preparatory for broad C06/C11 and full product retirement.
