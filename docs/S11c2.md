# S11c2 — observed live locator reconciliation

Implements S11c.md after qualified S11c1 owner claims. Sources owns locator
observations in its private database. Public locator_reconcile takes operation_id
and1..8 entries with path,expected_version and optional expected_device/inode.
A registered immutable version is a byte expectation, never authority to mutate
files. Sources verifies the configured root and each bounded file independently.
Results distinguish available/missing/changed/unsupported/uncertain observations
with observed_checkpoint freshness. Public locator_get reads owner-bound committed
history; exact reconcile retry returns history before root access. New operation
rechecks current paths. Immutable snapshot/evidence records remain unchanged.

Included native locator.c/h, Sources dispatch/Makefile/contracts, tests/test_locator.c
and public Agent/Sources receipt-driven observer test. Directory descriptors use
nofollow/nonblocking traversal; read <=1MiB through64KiB buffers, revalidate held
and named file/root/parents before committing available/absence. Missing parent
or file needs stable parent observation; root unavailable never proves absence.
Foreign expected-inode mismatch reports changed without adopting foreign bytes.
An expected registered SHA whose current bytes differ reports changed even if
metadata was restored. Unsafe/special/oversize files are unsupported.

Bounds256 locator associations,256 durable retry records, eight observations per
operation, request16KiB/path1024, output64KiB and existing160MiB database ceiling.
One locator writer,zero queued. Retry identity normalized and owner-bound; quota
admission before filesystem work, transaction persists observations/result together.
No deletion/eviction/caller private-state access/model/Python dependency.

Acceptance from S11c.md plus actual process barrier for changed file/directory and
quota/retry/offline/owner/cross-root cases. Native text/PDF/index regressions,
sanitizers and independently copied Mac/Linux releases; public effect receipts
are checked through Source API rather than consumed as freshness assertions.
Focused commands recorded when runner exists. Complete only after these pass.
