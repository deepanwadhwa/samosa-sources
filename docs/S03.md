# S03 — native bounded PDF text layer

C02/C05 subsets. Register an authorized immutable PDF snapshot, then read an
explicit 1-based inclusive range of at most four pages through Sources. Use the
published PDFium C ABI and pinned headers; optional host-configured dynamic
library. Plain text has no PDFium runtime requirement. No Python or interpreter
for fixtures, native extraction, tests, builds or tooling.

Sources owns binary captured bytes, format registration, evidence and extraction.
Host configuration gains --pdfium-library; requests cannot choose a library/path.
Register_pdf enforces existing capture/path/1 MiB limits and PDF signature. Read_pdf
requires source_id/version/start_page/end_page, checks registered PDF/hash,
loads only selected pages/text pages, emits absolute page citations and actual
page total. Text layer is always partial coverage: blank/scanned/visual regions
never masquerade as inspected. Per page <=65536 UTF-8 bytes; typed oversize/error
rather than silently dropping content. Entire selected batch <=4 pages.

Included: optional dynamic ABI adapter, reader contract, native C PDF fixture
writer, spy adapter forwarding actual PDFium while logging load/extract calls,
C contract/native checks and separate CLI tests. Source register_text/read_text
remain qualified. No cache, OCR, full visual coverage, real inference or App claim.
A standalone native test requires a configured external PDFium library; absence
is explicitly not a native pass. `make test`, `make sanitize`, `make test-pdf
PDFIUM_LIBRARY=/configured/libpdfium`, `make release`; repeat independently.

Acceptance: generated 100-page PDF sentinel on absolute page97, real extraction,
spy sees only selected page loads/text loads, out-of-range/>4-page refusal before
extractor, empty page remains text_layer_only, immutable read after live change,
malformed PDF rejected by native ABI, library missing leaves text functional.
Preparatory; superseded production paths cannot retire until broader gates pass.
