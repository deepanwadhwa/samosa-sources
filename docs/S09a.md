# S09a — bounded read-only folder inventory

C01/C02/C05/C06/C09 subset. Sources inventories a host-authorized selected folder
without Agent, model weights, action executor or content extraction. Public entries
carry relative locators, mechanical file identity, byte size/type and uninspected
content coverage. Inventory completeness is explicit and never implies full
content indexing or a global count from a shortlist.

Owner Sources; new owned inventory.c/h and tests, existing CLI/descriptor route.
No private Chutni/cache readers in consumers. Bounded max256 entries/depth4/
32 visited directories/path4096. No symlink traversal; special files ineligible.
Directory identity/change checks, typed inaccessible/stale errors, no automatic
full walk fallback. UTF-8 locators required; malformed names explicitly counted
and completeness qualified. Root is host configuration; request path is relative.

Acceptance: generated nested/duplicate-name/empty/symlink/FIFO fixtures; exact
bounded counts/completeness and uninspected content; deep/entry cap partial with
unknown total; escape/malformed/path refusals before traversal; Sources standalone
without Agent/model/action executor and copied native build/sanitize/release.
Later S09b adds resumable bounded index/retrieval; Agent pipeline/actions remain
separate assignments. No Python, no mutation to fixture source files by inventory.
