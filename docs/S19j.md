# S19j: continuous watch runtime

Sources owns an explicit CLI polling worker per registered watch. Owner-bound get
precedes private lease creation; checked kernel lease refuses duplicate workers.
Status inspects the lease rather than a stale PID/heartbeat file. Root identity,
state directory binding and runtime lease path binding cannot silently rebind.

Workers invoke public watch get/step, with100..60000ms intervals and five-second
per-observation deadlines. Signal/host cancellation is checked by existing bounded
hash/precommit control. Temporary writer contention/cycle conflict/race/deadline
retries after the interval; permanent scope/corruption/state failures end the worker.
Prior checkpoints remain readable. No unbounded event stream or queue is created.

Native process tests qualify actual content change/deletion, running status and
duplicate refusal, SIGTERM shutdown, SIGKILL release/restart, public stop, and
actual root/state replacement refusal with retained checkpoints. Both observer
parent tests and CLI worker are instrumented in sanitizer qualification.

Broader fair admission, health/failure reporting, long-running resources, multiwatch
concurrency, watch removal/replacement, automatic restart and reindex scheduling
remain open. This does not finish the entire freshness/watch/upload area or Sources.
