# S01 — native bounded immutable text reading

C01/C02/C05 subsets. Implement Sources in C11, using libc/POSIX and system
SQLite only. Python is prohibited in implementation, builds, tests and tooling.
Sources owns immutable registered bytes, source versions and literal evidence.
Public interface: one bounded JSON request on stdin, one JSON result on stdout;
`--root` supplies an authorized local directory, `--state` a private directory.
No parent/sibling headers, private state or gateway calls.

Operations: describe, register_text(path), read_text(source_id, version,
start_byte, end_byte). Every request requires contract_version=1. Registration
captures a regular file through descriptor-relative, no-symlink traversal,
checks identity before/after reading, validates UTF-8, and stores captured bytes.
SHA-256 content IDs remain immutable across later live changes. Reads verify
stored hashes and return literal text, inspected range, provenance and explicit
complete/partial coverage. Reject splitting UTF-8 code points.

Limits: request 16 KiB, depth 16, 256 JSON values, input 1 MiB, selected read
64 KiB, retained snapshots 128/128 MiB, SQLite 140 MiB. Refuse quota overflow;
no eviction of pinned versions. Private state is owner-only; SQL transactions
serialize admission. No executable reader/model dependency for plain text.

Acceptance: exact bytes/metadata; invalid ranges, malformed JSON/UTF-8,
oversized requests/files, symlink/path escape and corruption refusal; immutable
read after live replacement; reopen state in another process; concurrent quota
admission; SHA-256 known vectors. `make test`, `make sanitize`, `make release`.
Copy component to a temporary standalone root, build/test without the parent.

Preparatory: does not retire existing production reader paths. Excludes PDF,
OCR, models, indexing, Agent, App and filesystem mutations. Completion requires
actual checks and checkpoint evidence; broader C01/C02/C05 remain open.
