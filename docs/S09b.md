# S09b — bounded resumable source index and qualified retrieval

C02/C06/C09 subset. Sources owns folder index jobs, immutable captured manifest,
item checkpoints and exact indexed text. Public create/step/get/search operations
work without Agent, model or action executor. Indexing records content coverage
independently of folder inventory completeness; partial candidates never establish
absence/counts. Optional external Chutni remains behind this owner boundary.

Included: owner-local SQLite index job/item tables, fixed captured inventory,
explicit bounded step<=4 items, per-item transactional commit, max8 jobs/256 items
per job, bounded stored text/response quotas. Restart reuses finished items; a
mid-item crash resumes that uncommitted item only. No unbounded background scan.
Every item revalidates public mechanical identity before capture; changed/unsupported
item gets explicit failed/uninspected status. No implicit full document/PDF read.
Literal text is captured from immutable registration/read semantics; no model prose
enters literal index. Exact lexical search returns bounded candidates and coverage,
not a model-selected exhaustive answer. Enrichment comes in a separate assignment.

Acceptance: real generated folder index, step/restart reuse, actual worker SIGKILL
barrier between items, checkpoints agree, quota accepted/rejected counts, changed
file/source handling, partial inventory/search qualifications, search without
opening Sources storage in consumer. Native standalone tests/sanitizers/clean
release and public Agent candidate pipeline later. No Python or legacy index fallback.
