# S16b — bounded Sources DOCX reader

C02/C05/C06, Sources-only continuation after qualified HTML S16a. Copy the native
OOXML extraction primitive and licensed read-only miniz source into this package.
No legacy/sibling include/build paths, external unzip process or Python tooling.
Native fixtures construct actual stored and Deflate ZIP packages. This is
preliminary parser work until public registration/read/cache/control is delivered.

Public register_docx/read_docx follow immutable owner-scoped snapshot semantics.
Original OOXML bytes determine source/version IDs. Selected readable UTF-8 bytes
must explicitly use extracted coordinates. Evidence remains literal extracted
text with partial coverage for uninspected images/rendering/macros; generated
summaries are separate derived objects. Parser/fingerprint/range bind evidence.
Reuse existing bounded caches and durable read cancellation/deadline contracts.

Enforce original input1MiB, output64KiB, package entries2048, total declared
expansion8MiB, each entry/XML1MiB, auxiliary files64 and compression ratio200.
Validate paths, supported ZIP methods, duplicate names, CRC, required package
parts/content-type/relationships, strict XML UTF-8 and unsafe entity/DOCTYPE
refusal. Refuse invalid/oversized inputs before evidence publication or caching.
Retain original-byte snapshots through live changes and refuse corrupt state.

Native public tests must cover stored/Deflate extraction, entities/paragraphs,
header/footer ordering, deleted text exclusion, UTF-8 selectors, malformed ZIP,
traversal/duplicate/expansion/XML/output limits, authority, provenance, exact
cache/control retries, active cancellation/deadline and healthy survivors. Run
independent macOS/Linux normal and ASan/UBSan plus existing Sources/PDF/HTML
regressions and match release contents. No App/Agent/Inference changes required.
S16b does not close the remaining OCR/media/acquisition/enrichment/indexing/
Chutni/service requirements or whole Sources acceptance.
