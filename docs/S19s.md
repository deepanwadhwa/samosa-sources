# S19s: continuous local index runner

--index-run invokes the bounded automatic queue step continuously, paced by
--index-interval-ms100..60000 (default1000). One checked owner-only single-link
private kernel lease admits one runner per state directory. Duplicate processes
refuse queue_busy; SIGKILL releases admission for restart. No per-cycle files,
client receipts or streaming stdout accumulate.

The runner retains root scope/state directory/lease bindings and checks them
between attempts. Each attempt has a five-second deadline bounded by the host
deadline. Host cancellation and TERM/INT cancel work and interrupt paced waits.
Transient missing/stale/busy/deadline failures retry after the interval; permanent
quota/integrity/binding errors terminate. Item commit/checkpoint semantics remain
the automatic queue step's existing bounded durable semantics.

Native tests spawn the actual CLI and exercise duplicate admission, missing-file
retry alongside healthy progress, offline retained attempts, TERM/INT, SIGKILL and
restart, later-file recovery, root/state/private-lease replacement, and historical
evidence after replacement. Normal and ASan/UBSan configurations instrument both
runtime and test binary. Existing reindex and continuous watch regressions run too.

This qualifies the local paced runner, not a complete service. Per-item backoff,
precheck-to-dispatch/store-open race closure, long-running resources/fairness,
new/failed-file/legacy policies and full Sources/C01–C14 remain open.
