# S18b — optional native compressed-media workers

Continue Sources C02/C05/C06 media requirements after plain WAV preparation and
its qualified owned cache. Required compressed formats include MPEG audio,
MP4 audio/video and QuickTime video. Decode/resample audio to bounded PCM16
mono16000Hz windows; prepare bounded timed visual frames separately. Preserve
absolute source time, selected stream, container origin, conversion method,
source/version/fingerprint and owner locator. Neither prepared media nor generated
analysis is literal transcription. The full media scope is retained.

Use an optional Sources-owned executable linked to declared native FFmpeg SDK
dependencies. Default Sources builds/reads/WAV preparation require no FFmpeg
headers or libraries. Host configuration selects a verified decoder artifact;
request bodies cannot choose executables, libraries or paths. Reuse the owned
native worker boundary: bounded input/output/protocol, independent process group,
RSS/descriptor/CPU/core limits, exact cancellation/deadline, peer/caller death,
reaping and parent validation before publication/cache. Do not spawn a new public
service or give the decoder Sources SQLite/private sibling state.

Host SourcesConfig.media_helper / CLI --media-helper selects the optional codec
worker independently of the standard native_helper used for PDF/OCR. Missing
media configuration returns media_unavailable. Private fingerprint queries and
audio decode DTO validation are implemented; public media/cache routing remains.

Demux immutable copied input through custom read/seek memory IO. Refuse secondary
files and network IO. Bound streams, metadata, packet/frame dimensions, decoder
threads, duration and selected output. Codec callbacks supplement owning process
teardown; a stalled decoder must not need to return before cancellation completes.
Do not silently pad/truncate or relabel gaps/discontinuous timestamps as complete
selected coverage. Explicitly describe/refuse unsupported layouts/time coverage.

Fingerprints bind reader/selection/conversion contracts and the actual configured
executable plus loaded codec/demux/resampler artifacts. Version strings alone are
insufficient. Check artifacts before/after work, qualify exact cache reuse and
preserve prior good entries when configuration changes or native work fails.

The optional primitive now hashes its executing image and loaded demux, codec,
resampler and utility images. Kernel mapping inode/device must match the opened
files, and descriptor/path identities are checked before/after decode. Actual
WAV and compressed/reference fixtures pass normal and ASan+UBSan on macOS/Linux,
including a different mapped-image inode refusal. Owned worker routing, queried
fingerprint binding, public registration/preparation/cache and parent validation
are implemented. Public durable cancellation in fingerprint/decoder phases,
cache tamper/capacity, peer isolation/RSS limits and exact reaping pass normal/
sanitizers on macOS/Linux. Descendant cancellation passes macOS normal/sanitizers
and Linux normal/sanitizers. Caller-death checks pass normal/sanitizers on both
platforms, including a subsequent healthy decoder.
Broader codec/timeline corpus, timed visual frames, larger uploads and final
independent optional package qualification remain required.

Initial SDKs available: macOS avformat63.1.102/avcodec63.1.102/swresample7.1.102;
Debian ARM64 avformat59.27.100/avcodec59.37.100/swresample4.7.100 (FFmpeg5.1.9).
Installed upstream headers are primary API references; compile against each
platform's declared SDK, without copying their private structs between versions.
Qualify native generated audio/video fixtures, actual codecs/resampling and source
timestamps, malformed/oversized/secondary-reference inputs, cache/control/peer
failures, independent minimal/optional builds, sanitizers and releases on both
platforms. Installation alone is not decoder implementation or qualification.

Sources neural extraction uses an explicit public Inference adapter contract with
scoped operations, owner/parent/deadline, prepared artifact identity and qualified
text/frame/timestamp provenance. Inference currently lacks media operations;
define the Sources adapter/unavailable behavior now and implement Inference in
its component turn. Actual model/provider and assembled media qualification remain
mandatory before full rebuild closure. Sources acquisition, storage/enrichment,
uploads/live sources and authenticated bounded service also remain required.


Timed visual worker qualification now covers actual frame DTO delivery, parent
range/dimension/byte-count/timestamp/stream/matrix/range/payload validation,
queried fingerprint binding, crash/protocol/output/stall, active cancellation/
deadline, RSS bounds, exact reaping, healthy visual peers and caller/descendant
death. Normal and ASan+UBSan checks pass on macOS and native ARM64 Linux with the
bounded timed-frame fixture. Run the existing worker targets with an explicit
video fixture and `MEDIA_MODE=--visual`; default audio checks remain available.
This qualifies the worker boundary for that fixture, not the broader codec,
color/orientation corpus or public visual preparation/cache.

Public `prepare_visual` is now implemented with registered encoded-media owner
claims, immutable snapshot digest checking, visual selection contract identity,
original-time/stream/dimension/color DTO provenance, the shared prepared cache,
cache DTO validation and durable parent/cancellation/retry controls. It reuses the
bounded common media preparation path; audio and visual artifacts have distinct
identities for the same source/range. See contracts/media-v1.md.

Reproducible public fixture checks use `make test-media-public
MEDIA_FIXTURE=/absolute/native-video.mp4 MEDIA_KIND=visual` and
`make test-media-cache MEDIA_HELPER=/absolute/configured-worker
MEDIA_FIXTURE=/absolute/native-video.mp4 MEDIA_MODE=--visual`. The cache fixture
currently expects the qualified 64x64 blue frame at source second 1 and an audio
track, so these are corpus fixture assertions, not generic file diagnostics.
Sanitizer counterparts accept the same modality selectors. Current qualification
is recorded in the architecture verification checkpoint; broad media and final
component release remain incomplete.

Orthogonal presentation work now adds integer rotations/reflections after the
bounded RGBA conversion, frame/stream matrix provenance and required parent/cache
orientation/shape validation. Frame-side matrix takes precedence over stream
metadata. Both supported FFmpeg API generations have native paths (new codec
parameter side data, older stream side data); no sibling implementation or extra
runtime SDK is introduced. Worker-v3 fingerprints bind the changed method.

The owned native fixture writer patches a generated one-track MP4's track matrix
without changing its compressed pixels. `test-media-orientation` and
`sanitize-media-orientation` compare all eight transforms with separately executed
native FFmpeg scale/color/RGBA/presentation references. The native harness now
checks primitive, worker, public `prepare_visual` and exact cache hits for every
case. A shear fixture checks typed refusal, no artifact and exact offline public
durable retry. Use explicit `MEDIA_CORPUS_DIR` and, for sanitizers, an explicitly
instrumented `MEDIA_HELPER`. Broader timeline/color and final optional component
packaging remain required; this is not full media or component closure.


Expanded color/timeline corpus now covers native VP9/MP4, full-range H.264,
10-bit SDR BT.2020 HEVC, video delayed1.2s behind an early audio track, a video
track absent from the selected interval, and sparse variable frame timing. The
harness checks expected source microseconds independently (including1.2s and
1.12s), complete native reference RGBA, public metadata and exact cache reuse.
Uncovered intervals yield typed no-artifact refusal and exact offline durable
retry. Original encoders use explicit timestamp passthrough/VFR controls on both
SDK generations; default encoder duplication is not used as timeline evidence.
HDR tone mapping, broader gamut/transfer and format coverage remain separate
requirements; no broad visual-quality claim is implied by these exact cases.
