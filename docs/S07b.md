# S07b — bounded Sources-owned evidence reuse

C06 subset. Cache successful qualified literal reads under exact source/version,
selector, reader contract and extractor fingerprint. Return byte-identical public
qualified evidence on hit, including partial coverage; never infer full coverage.
Consumers use public reads only. Sources alone owns cache schema and corruption
checks. Failed/derived output is never admitted as literal cache evidence.

Included: text/PDF reuse in existing owner-local SQLite, transactional cache
admission,128 entries/8MiB bounded total/2MiB per response, no eviction. Cache
capacity refusal before new extraction; corrupted response digest typed refusal.
Native spy hit skips PDF page/text load, changed artifact misses, bad extraction
not cached, exact retry stable. Host can lower limits for native quota tests.

Acceptance: text/PDF C tests and spies; actual cache fill with accepted/rejected
counts; malformed/error/partial separation; independent test/sanitize/release and
public Agent interaction with copied Sources. No caller cache-path/storage parsing.
Completion is bounded cache subset, not indexing/OCR/web/media/live-file actions.
No Python in any implementation/build/test/tooling. No legacy cache fallback.
