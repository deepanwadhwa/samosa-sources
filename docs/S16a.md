# S16a — Sources HTML reader

Component-local continuation of C02/C05/C06. Sources owns immutable HTML bytes,
bounded deterministic extraction, selected evidence and reuse. The existing
native dependency-free HTML parser is copied into this independent codebase;
no build references to legacy or sibling source paths are permitted. Retain
script/style/template/head/SVG/iframe/object suppression, entity decoding,
strict UTF-8 validation, output bounds and malformed-input refusal. Extracted
readable text is literal extraction, never model-generated enrichment.

Public delivery: register_html uses the authorized root, content identity,
owner claim and immutable snapshot limits of existing registration. read_html
selects exclusive UTF-8 byte offsets in the extracted readable-text coordinate
space, explicitly identified in range/provenance. Preserve source/version IDs
from original bytes, reader fingerprint, partial HTML coverage (rendered images,
CSS and dynamic content are not inspected), exact evidence identity and scoped
cache/control semantics. Refuse oversized decoded output without caching partial
text. No App/Agent/Inference changes are needed to deliver or test this contract.

Acceptance includes native parser and public CLI/library checks, owner refusal,
original-byte identity, selected UTF-8 boundaries, ignored executable/hidden markup,
output limits, snapshot corruption, exact cache retry and cancellation/deadline
behavior. Run regular and ASan/UBSan tests in independently copied macOS/Linux
roots and package only after public acceptance. Parser-only checks are preliminary,
not HTML public delivery or Sources component completion.

Whole Sources closure still requires DOCX/OCR/media, fetch/search, indexing and
derived enrichment, external Chutni integration, bounded authenticated service,
full limits/failure/resource/platform acceptance and independent releases.
