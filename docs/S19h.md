# S19h: durable watch registry

Sources owns bounded watch registration/get/stop behind public locator operations.
Registry retains owner/root scope, normalized request identity and checked immutable
version ownership. Kernel writer lease serializes admissions; a second retry check
after acquisition closes the pre-lease duplicate race. Registration/status is
usable offline, and stopped watches retain their original registration.

Native tests cover owner/root registration, offline duplicate retry, conflicting
parameters, owner refusal, offline status, repeated stop, missing live files and
eight-watch capacity refusal. Existing locator tests remain required. Registered
watches explicitly report not_running until a Sources-owned runtime is implemented.
This is lifecycle groundwork, not completed continuous watching or full Sources.
