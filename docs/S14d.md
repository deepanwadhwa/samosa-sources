# S14d — durable Source read operations

C02/C05/C06/C11 continuation. Add owner-scoped operation_get/operation_cancel and
tracked read_text/read_pdf/inventory when operation_id is present. Parent IDs
remain references, not authority. Normalize selectors, requested relative budget
and parent into retry identity; unchanged completed/failed/cancelled retries are
served offline. Changed parameters refuse. Untracked reads retain their contract.

Sources owns its operation metadata, cancellation signals and kernel worker
leases in its private state directory. Agent never reads that storage. Bound
history128, live workers8, result2MiB, aggregate committed+reserved results32MiB
and operation database64MiB. No silent history eviction. Malformed fields refuse
before operation admission. Interrupted worker recovery must distinguish dead
leases from live peers and expose exact terminal status. No unqualified replay
of interrupted provider work. Failed/cancelled/deadline reads do not authorize
new Agent evidence. An already valid cache entry is independent of run status;
cache population is not claimed atomic with operation cancellation.

Poll per-operation cancellation alongside inherited host cancellation/deadline.
Serialize public cancel intent and terminal publication. Terminal success racing
cancellation is authoritative; no completed worker or unrelated ID is cancelled.
Durable status includes exact operation/parent, status and cancel_requested.
A scoped callback cannot interrupt a blocking foreign native/syscall; own helper
teardown and bounded cleanup remain required. No hard kernel/fsync guarantee.

Qualify strict fields/budget/owner, normalized retry/conflict, unchanged evidence
identity, result digest corruption, actual concurrent cancellation/peer survivor,
worker SIGKILL recovery,128-history/quota and foreign/symlink refusal. Exercise
native PDF cancellation at page boundaries on declared hosts. Integrate Agent
public exact-child Source control, verify external terminal vs unconfirmed and
last-good behavior. Independently build/sanitize/package macOS and ARM64 Linux.
All service/auth/App/load/scheduler/retirement gates remain open until separately
implemented and qualified.
